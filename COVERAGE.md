`COVERAGE_AUDIT.md` is the table for the original 109-symbol playback-only audit. It counts top-level symbols only (classes, protocols, constants, typedefs), so it says nothing about members; this matrix documents the families wrapped beyond that set.

## Not wrapped

- `AVPlayerView` and the rest of AVKit (a different framework).
- The `AVVideoComposition` / `AVMutableVideoComposition` and `AVAudioMix` object models: `PlayerItem` can only build a composition from an asset's properties, set per-track audio-mix volumes, report whether either is set, and clear them.
- `AVPlayerItem.externalMetadata` (not available on macOS in the SDK this crate builds against).
- The Swift-only `AVAssetReader.Provider` / `outputProvider(for:)` API added in macOS 26.
- Delivery of `AVAssetReaderOutput` samples through a provider or asynchronously; `copy_next_sample_buffer` is synchronous.
